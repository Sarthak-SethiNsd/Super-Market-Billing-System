# Supermarket Billing System

## Overview

The Supermarket Billing System is a C++ desktop application designed to automate billing and inventory-related operations in a supermarket environment.

The system allows customers or cashiers to:
- View available products
- Add items to a bill
- Update item quantities
- Remove items from a bill
- Calculate GST
- Generate final bills
- Store transaction records

It also supports daily sales report generation.

## Features

- View Product Catalog
- Display Product Price
- Display Available Stock Quantity
- Display GST Rate
- Add Item to Bill
- Update Item Quantity
- Remove Item from Bill
- Calculate GST
- Generate Final Bill
- Save Bill to File
- Generate Daily Sales Report

## Sample Billing Flow

1. View available products.
2. Select a product.
3. Enter quantity.
4. Validate stock availability.
5. Add item to bill.
6. Calculate subtotal.
7. Calculate GST.
8. Generate total payable amount.
9. Save bill to file.
10. Print receipt.
